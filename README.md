# Fayroz Site Calculator

تطبيق Android Native سريع لحساب كميات الموقع ضمن عائلة برامج **FAYROZ**.

## طرق الاستخدام
- **حسب الفراغ:** أدخل أبعاد الغرفة أو الحمام أو المطبخ مرة واحدة واختر البنود المطلوب حصرها.
- **حسب البند:** اختر البند مباشرة وأدخل أبعاده.

## البنود الحالية
المحارة، الدهانات، الأرضيات، سيراميك الحوائط، الوزرات، المباني، العزل، والجبس بورد.

الهوية البصرية مبنية على نفس نظام **Fayroz Estimator**.
